# Thuốc ơi — Landing page

Trang landing page cho [Thuốc ơi](https://github.com/Tuandiep98/thuocoi), app Flutter hỗ trợ lên lịch uống thuốc thông minh từ ảnh đơn thuốc. Build bằng [Astro](https://astro.build), static, không dùng framework UI phía client.

## Chạy dự án

```sh
npm install
npm run dev       # dev server (chạy nền — dừng bằng `npx astro dev stop`)
npm run build     # build production vào dist/
npm run preview   # xem thử bản build
npx astro check    # type-check
```

Xem `CLAUDE.md` để biết kiến trúc chi tiết và danh sách placeholder cần điền trước khi lên production (link App Store/Google Play, domain thật, trang chính sách quyền riêng tư/điều khoản).
